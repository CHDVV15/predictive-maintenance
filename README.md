# Predictive Maintenance for Industrial Equipment

## Overview

This project predicts equipment failures using machine learning and provides maintenance recommendations.

## Features

* Failure prediction using Random Forest
* Real-time monitoring simulation
* Automated alerts
* Equipment health score
* Interactive dashboard

## Technologies Used

* Python
* Scikit-Learn
* Streamlit
* Pandas
* Matplotlib

## Dataset Features

* Footfall
* Temperature Mode
* Air Quality
* Ultrasonic Sensor
* Current Sensor
* VOC
* RP
* Input Pressure
* Temperature

## Model

Random Forest Classifier

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
